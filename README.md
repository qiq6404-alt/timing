# 判断时机 · 势·牌·心 三灯自检

情绪高涨时，判断「要不要现在出牌」的通用方法。

适用：辞职、跳槽、all-in 一个方向、结束一段关系——任何想做重大决定的时刻。

## 核心思想

情绪是快系统，时机判断是慢系统。情绪最高点，恰好是判断最脆弱的点。

时机不是投机，是「我什么时候出牌」，由三盏灯决定：

| 灯 | 问自己 | 亮（可以出） |
|----|--------|--------------|
| **势** | 外部窗口真的开了吗？ | 有具体证据，不是「觉得」 |
| **牌** | 这次输了会不会下桌？ | 输了也不会下桌 |
| **心** | 这是判断，还是想逃？ | 想清楚了要去哪 |

出牌规则：

- **三灯全亮** → 出牌，别犹豫。
- **两盏半亮** → 先把那半盏补上再动。
- **一盏不亮** → 不出。那是冲动，不是时机。
